SECTION 1 — AUTHORITATIVE PIN MAP (copy these exactly, do not change)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

These are the GPIO assignments from the firmware. The PCB must match exactly.
Changing any pin requires a firmware code change — do not do this without
checking with Ramayana first.

  INMP441 Microphone (I2S):
    GPIO 3  → SD   (serial data out from mic)
    GPIO 4  → WS   (word select / LRCK)
    GPIO 5  → SCK  (bit clock / BCLK)
    3.3V    → VDD
    GND     → GND
    GND     → L/R  (ties mic to left channel)

  MicroSD Card Module (SPI):
    GPIO 6  → SCK
    GPIO 7  → MOSI
    GPIO 2  → MISO
    GPIO 10 → CS   (chip select)
    VCC     → VCC  (see note below)
    GND     → GND

    SD VCC → VIN rail (same rail as ESP32 VIN, fed from SW2 PIN A)

    NOTE: This module is a 5V module with an onboard 3.3V LDO regulator.
    Connect its VCC to the VIN rail, NOT to the ESP32's 3.3V pin.

    The VIN rail is:
      - ~5V when USB is plugged in (TP4056 passing USB power through)
      - ~3.7–4.2V when running on battery only

    The onboard LDO regulator on the SD module requires only ~3.5V minimum
    input, so it works correctly across the full battery discharge range.
    Do NOT power the SD module from ESP32's 3.3V pin — it cannot supply
    enough current for reliable SD card writes.

  SW1 — Recording Toggle (SPDT, 3-pin):
    GPIO 8  → COMMON (middle pin)
    3.3V    → PIN A  (flip this way = START recording)
    GND     → PIN B  (flip this way = STOP recording)

  SW2 — Power Switch (SPDT, 3-pin):
    XL6009E1 OUT+ (5V regulated) → COMMON (middle pin)
    ESP32 VIN +
    SD VCC        → PIN A  (ON — 5V flows to all modules)
    NC            → PIN B  (OFF — leave unconnected)

    NOTE: XL6009E1 IN+ connects to TP4056 B+ (battery positive directly).
    Do NOT connect XL6009E1 to TP4056 OUT+. Doing so causes the TP4056 to
    never complete charging (red LED stays on forever). The boost converter is
    ALWAYS running from the battery. SW2 only switches its 5V output.

  LED1 — Green (status/online):
    GPIO 0  → R1 (220Ω) → LED1 anode → LED1 cathode → GND

  LED2 — Red (recording):
    GPIO 20 → R2 (220Ω) → LED2 anode → LED2 cathode → GND

  Battery Voltage Divider:
    LiPo BAT+ → R3 (100kΩ) → GPIO 1 (ADC) → R4 (100kΩ) → GND

    GPIO 1 is ADC-only. Do NOT connect any other signal to it.
    This divider halves battery voltage: max 4.2V → 2.1V at GPIO1,
    safely within the ESP32's 3.3V ADC input range.

    Optional but recommended: 100nF ceramic cap from GPIO1 to GND,
    placed right at the GPIO1 pad, to filter ADC switching noise.

SECTION 3 — PHASE 1: BREADBOARD PROTOTYPE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Build and test on a breadboard before designing the PCB.
This saves you from re-spinning the board due to a wiring mistake.

STEP 1 — Power rails
  a. Connect TP4056 USB-C to a USB power source.
  b. TP4056 B+ → XL6009E1 IN+  (battery positive directly to boost converter IN+)
     TP4056 B- / GND → XL6009E1 IN- (GND)
     IMPORTANT: Connect to B+, NOT to TP4056 OUT+. If you wire XL6009E1 to
     OUT+, the TP4056 charging LED will stay red forever and the battery will
     never reach full charge.
  c. BEFORE connecting anything else: power the XL6009E1 alone (connect a
     3.7V source to its IN+ and GND), then measure its OUT+ with a multimeter.
     Turn the trim pot until you read exactly 5.0V. Too high destroys the ESP32.
  d. XL6009E1 OUT+ → SW2 COMMON, XL6009E1 OUT- → GND rail.
  e. SW2 PIN A → ESP32 VIN + SD VCC. SW2 PIN B → leave unconnected.
  f. Flip SW2 to ON. Measure 5V at ESP32 VIN, and 3.3V at ESP32 3V3.
     If you get anything other than ~5V at VIN, stop and recheck.

  IMPORTANT — battery voltage divider taps from TP4056 B+ (raw battery):
  TP4056 B+ → R3 → GPIO1 → R4 → GND
  Do NOT tap the divider from XL6009E1 OUT+. That rail is always 5V and
  would tell the firmware the battery is always full.

STEP 2 — Recording switch (SW1)
  e. SW1 COMMON → GPIO8.
  f. SW1 PIN A (start) → 3.3V rail.
  g. SW1 PIN B (stop)  → GND rail.
  h. Add PULLDOWN resistor (10kΩ) from GPIO8 to GND if the firmware
     does not already enable INPUT_PULLDOWN (it does — but good practice).

STEP 3 — LEDs
  i.  GPIO0  → R1 (220Ω) → LED1 anode → LED1 cathode → GND.
  j.  GPIO20 → R2 (220Ω) → LED2 anode → LED2 cathode → GND.
  Note: LED anode is the LONGER leg. Cathode (shorter leg) goes to GND.

STEP 4 — Battery voltage divider
  k. LiPo BAT+ → R3 (100kΩ) → junction point A → R4 (100kΩ) → GND.
  l. Junction point A → GPIO1.
  m. Optional: 100nF cap from GPIO1 to GND right at the junction.
  VERIFY: with a 3.7V battery, measure ~1.85V at GPIO1 with a multimeter.

STEP 5 — Decoupling capacitors (C1, C2, C3, C4, C5)
  Place these BEFORE powering on. They filter voltage spikes and keep the
  power rails clean. Without them the ESP32 can reset randomly during WiFi
  transmit or SD card writes.

  C1 — 100µF electrolytic (bulk decoupling on VIN rail):
    +leg (longer) → VIN rail (5V)
    -leg (shorter, marked with stripe) → GND
    Place as close as possible to ESP32 VIN pin.
    IMPORTANT: electrolytic caps are POLARISED — wrong way = damaged or explodes.

  C2 — 10µF electrolytic (mid-frequency decoupling on VIN rail):
    +leg → VIN rail (5V)
    -leg → GND
    Place right next to C1, also near ESP32 VIN.
    C1 and C2 work together in parallel — C1 handles slow big spikes,
    C2 handles faster ones.

  C3 — 100nF ceramic (high-frequency decoupling on 3.3V rail):
    One leg → ESP32 3V3 pin (3.3V output of ESP32's onboard LDO)
    Other leg → GND
    Place as close as possible to the ESP32 3V3 pin.
    Ceramic caps have NO polarity — either leg can go either way.

  C4 — 100nF ceramic (INMP441 microphone VDD decoupling):
    One leg → INMP441 VDD pin (3.3V)
    Other leg → GND
    Place as close as possible to the INMP441 VDD pin — within 2mm on PCB.
    This stops power-supply noise from getting into the audio signal.

  C5 — 100nF ceramic (ADC noise filter on GPIO1):
    One leg → GPIO1 (the junction between R3 and R4)
    Other leg → GND
    Place right at the GPIO1 pad.
    This smooths out switching noise so the battery % reading is stable.

STEP 6 — MicroSD card module
  n. SD SCK  → GPIO6, SD MOSI → GPIO7, SD MISO → GPIO2, SD CS → GPIO10.
  o. SD VCC  → VIN rail (5V from USB, or battery voltage ~3.7-4.2V on battery).
              Do NOT use the 3.3V pin — insufficient current for SD writes.
  p. SD GND  → GND.

STEP 7 — INMP441 microphone
  q. INMP441 WS  → GPIO4.
  r. INMP441 SCK → GPIO5.
  s. INMP441 SD  → GPIO3.
  t. INMP441 VDD → 3.3V.
  u. INMP441 GND → GND.
  v. INMP441 L/R → GND (sets left channel — required).

STEP 8 — Flash firmware and test
  - Open Arduino IDE.
  - Board: "ESP32C3 Dev Module".
  - Upload Speed: 921600.
  - Tools → USB CDC on Boot: Enabled.
  - Flash the firmware from:
    voice-ai-architecture/firmware/voice_ai_hardware/voice_ai_hardware.ino
  - Open Serial Monitor at 115200 baud.
  - Expected boot sequence:
      [LED]  Green LED ON (WiFi connected)
      [BAT]  Battery: XX%
      [SD]   SD card OK
      [I2S]  Microphone ready
  - Flip SW1 UP → red LED on, "Recording started" in serial.
  - Flip SW1 DOWN → red LED off, file uploads, appears on web app.

SECTION 5 — PHASE 3: PCB LAYOUT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Board spec:
  - Size: 60mm × 60mm
  - Layers: 2 (top copper + bottom copper)
  - Surface finish: HASL (cheapest, fine for this application)
  - Minimum trace: 0.25mm signal, 0.5mm power (1mm preferred for power)
  - Min hole size: 0.3mm

PLACEMENT ORDER (place in this sequence):
  1. ESP32-C3 Super Mini — centre of board, antenna end pointing AWAY from
     all other components (see antenna keepout below).
  2. INMP441 — top edge of board, directly under the lid's mesh hole.
     Orient so the sound port on the module faces UP (toward lid).
  3. MicroSD module — right edge, slot facing outward so card is accessible
     from the side of the enclosure without opening it.
  4. TP4056 — bottom edge near the USB-C port cutout side.
  5. SW2 (power switch) — side edge, accessible from the enclosure cutout.
  6. SW1 (toggle switch) — opposite side edge from SW2, accessible from
     its enclosure cutout.
  7. LED1 (green) + LED2 (red) — bottom edge, facing the LED holes in the
     base of the enclosure. LED bodies must align with hole positions.
  8. Decoupling caps — place physically adjacent to the IC they serve:
       C1, C2, C3 → within 3mm of ESP32 VCC/VIN pins
       C4         → within 2mm of INMP441 VDD pin
       C5         → within 2mm of GPIO1 pad
  9. R3 + R4 (voltage divider) — near the TP4056 BAT+ pad, not near the
     I2S or SPI signal lines.
  10. R1, R2 — between the ESP32 GPIO pads and each LED.

ROUTING RULES:
  - Power traces (VCC, GND, BATT): 1mm width minimum.
  - Signal traces (I2S, SPI, GPIO): 0.25mm minimum.
  - Keep I2S traces (GPIO 3, 4, 5) SHORT and away from SPI traces (GPIO 6, 7, 2).
    Running them parallel couples noise from SD writes into the mic audio.
  - Keep GPIO1 (ADC) trace under 20mm and away from I2S and SPI lines.
    Switching noise from those buses will degrade the battery reading accuracy.
  - Via size: 0.8mm outer / 0.4mm drill minimum.

GROUND PLANE:
  - Add a copper pour on the BOTTOM layer, assigned to GND net.
  - This shields the microphone from EMI from the SD card and WiFi radio.
  - Fill the entire bottom layer except the antenna keepout zone.

ANTENNA KEEPOUT ZONE (CRITICAL):
  - The ESP32-C3 Super Mini has a PCB trace antenna on one short end of the module.
  - That end of the board (and ~5mm beyond it) must have:
      NO copper pour (top or bottom)
      NO traces routed beneath the antenna
      NO components placed in that zone
  - Mark it clearly as a keepout region in EasyEDA.
  - WiFi range drops by 50–80% if you ignore this.

AUDIO QUALITY LAYOUT RULES:
  - INMP441 must be at least 15mm away from the ESP32 antenna.
  - INMP441 VDD decoupling cap C4 must be within 2mm — the shorter the trace,
    the less power-supply noise couples into the audio signal.
  - Consider adding a ferrite bead (600Ω at 100MHz) in series with INMP441 VDD
    between the 3.3V rail and C4. This blocks high-frequency switching noise
    from the LDO and SD card SPI bus from getting into the microphone.
  - If the SD module and INMP441 module are on the same layer, add a ground
    pour island between them on the top layer to act as a shield.

SECTION 7 — COMMON MISTAKES TO AVOID
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

MISTAKE 1: Swapping I2S and SPI pins
  ChatGPT and other AI tools frequently suggest the wrong GPIO assignments.
  The correct wiring from the firmware is:

  CORRECT (from firmware):           WRONG (commonly suggested by AI):
  I2S WS  = GPIO4                    I2S WS  = GPIO25  ← wrong chip
  I2S SCK = GPIO5                    I2S SCK = GPIO26  ← wrong chip
  I2S SD  = GPIO3                    I2S SD  = GPIO34  ← wrong chip
  SD SCK  = GPIO6                    SD SCK  = GPIO18  ← wrong
  SD MOSI = GPIO7                    SD MOSI = GPIO23  ← wrong
  SD MISO = GPIO2                    SD MISO = GPIO19  ← wrong

  Always use Section 1 of THIS document — not an AI suggestion — as the
  authoritative pin reference.

MISTAKE 2: LED2 on GPIO1
  GPIO1 is reserved for the battery ADC. Do NOT connect LED2 to GPIO1.
  LED2 (red, recording) is on GPIO20. This was changed from an earlier
  version of the design — make sure you have the current pin map.

MISTAKE 3: Connecting other signals to GPIO9
  GPIO9 is the ESP32-C3's built-in boot button with a hardware pull-up.
  It is NOT available as a general GPIO. Leave it unconnected on the PCB.

MISTAKE 4: Tapping the battery divider from the 5V/TP4056-OUT rail
  The voltage divider for GPIO1 must tap from LiPo BAT+ directly
  (before SW2), not from the TP4056 output after the switch.
  This ensures the firmware reads the actual battery voltage even when
  USB is plugged in, and the reading is correct throughout the full
  discharge curve (3.0V–4.2V).

MISTAKE 5: Ground plane under the antenna
  No copper under the ESP32 antenna. Any copper there detunes the antenna
  and kills WiFi range. Even a GND via under the antenna is harmful.

MISTAKE 6: LED installed backwards
  LED anode = longer leg = connect to resistor side (GPIO side).
  LED cathode = shorter leg / flat side on body = connect to GND.
  If both LEDs don't light up after flashing, check orientation first.

MISTAKE 7: SD card not formatted or wrong filesystem
  MicroSD must be formatted as FAT32. Cards over 32GB need special tools
  (Windows only formats >32GB as exFAT, which the SD library can't read).
  Use a card 8GB–32GB, format with SD Card Formatter from sdcard.org.
