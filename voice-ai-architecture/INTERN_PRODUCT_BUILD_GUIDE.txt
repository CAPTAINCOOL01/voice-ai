SECTION 1 — WHAT THIS DEVICE DOES
================================================================================

VoiceNote AI is a pocket-sized AI voice recorder that:

  1. Records audio via a digital I2S MEMS microphone (INMP441)
  2. Saves the recording as a .WAV file on a MicroSD card
  3. Connects automatically to WiFi on boot
  4. When recording stops, uploads the WAV file to a cloud server over HTTPS
  5. The cloud backend transcribes the audio using OpenAI Whisper
  6. The user views transcripts, AI summaries, and tasks in a web app

User controls:
  - SW2 (power switch)  → 3-pin SPDT slider: slide to turn the whole device ON / OFF
  - SW1 (record switch) → 3-pin SPDT slider:
                            slide toward 3.3V = starts recording (GPIO4 reads HIGH)
                            slide toward GND  = stops recording, saves file, uploads

The firmware is COMPLETE and TESTED. The intern's job is hardware only.
Do NOT modify any code. Do NOT change any GPIO pin assignments.

NOTE on R3 + R4 (voltage divider):
  These two resistors allow the ESP32 to measure the LiPo battery voltage and
  report battery percentage (0–100%) to the web app in real time.
  They form a simple 50% voltage divider:
    BAT+ → R3 (100kΩ) → GPIO34 (ADC) → R4 (100kΩ) → GND
  The divider halves battery voltage (max 4.2V → 2.1V) so it stays within
  the ESP32's 3.3V ADC input range. Do not change resistor values.

SECTION 4 — POWER ARCHITECTURE (wire in this exact order)
================================================================================

The XL6009E1 boost converter steps up battery voltage to 5V.
The TP4056 handles charging. SW2 only cuts power to the ESP32 and peripherals.
The battery always remains connected to both TP4056 and XL6009E1 so it charges
from USB even when the device is switched OFF.

  USB-C ──────────────────→ TP4056  IN+ / IN−
                                │
                           TP4056  B+ / B−  ←──→  LiPo Battery (always on)
                                │
                                ├──→ XL6009E1 IN+ / IN−  (boost, always on)
                                │         │
                                │   XL6009E1 OUT+ (5V regulated)
                                │         │
                                │   SW2 COMMON (middle pin)
                                │    │             │
                                │  PIN A          PIN B
                                │ (ON position)  (NC — not connected)
                                │    │
                                └────┴──→ ESP32 VIN + SD VCC

  SW2 wiring summary (3-pin SPDT):
    COMMON (middle) → XL6009E1 OUT+ (5V)
    PIN A           → ESP32 VIN + SD VCC
    PIN B           → NC (leave unconnected)

  Battery voltage divider taps from TP4056 B+ (raw battery voltage):
    TP4056 B+ → R3 (100kΩ) → GPIO34 (ADC) → R4 (100kΩ) → GND
  Do NOT tap from XL6009E1 OUT+. That is always 5V and will read 100% forever.

  CRITICAL — set XL6009E1 output to exactly 5.0V BEFORE connecting to board:
    Power XL6009E1 alone from a 3.7V source, measure OUT+ with multimeter,
    trim the pot to 5.0V. Too high destroys the ESP32.

  CRITICAL — connect XL6009E1 IN+ to TP4056 B+, NOT TP4056 OUT+:
    If wired to OUT+, the TP4056 charging LED stays red forever and the
    battery never fully charges.

  TP4056 LED indicators (on the module itself):
    Red  LED lit = currently charging
    Blue LED lit = fully charged
    Both off     = no USB power / battery not connected

SECTION 6 — PHASE 1: BREADBOARD VERIFICATION
================================================================================

Before designing any PCB, confirm the full system works on a breadboard.
This catches wiring mistakes cheaply. Do not skip this phase.

STEP 1 — Flash the firmware
──────────────────────────────
  Software needed:
    - Arduino IDE 2.x (download from arduino.cc)
    - ESP32 board package installed in Arduino IDE

  Install ESP32 board package:
    Arduino IDE → File → Preferences → Additional Boards Manager URLs:
    Paste: https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
    Then: Tools → Board → Boards Manager → search "esp32" → install

  Board settings in Arduino IDE:
    Board:            ESP32 Dev Module
    Upload Speed:     921600
    Flash Mode:       DIO
    Partition Scheme: Default 4MB with spiffs
    Port:             whichever COM port appears when ESP32 is plugged in

  Open firmware file:
    voice-ai-architecture/firmware/voice_ai_hardware/voice_ai_hardware.ino

  Credentials are stored as environment variables on the server — you do not
  need to edit the firmware. If credentials are needed for testing, ask Ramayana.

  Click Upload. Wait for "Done uploading."

STEP 2 — Wire the breadboard
──────────────────────────────
  Wire exactly as per Section 3.
  Use jumper wires. Power from USB (3.3V from ESP32's onboard regulator is enough
  for breadboard testing — no TP4056 needed yet for this step).

  Breadboard power rail:
    ESP32 3.3V pin → + power rail
    ESP32 GND      → − power rail

  Wire INMP441:
    VDD → 3.3V rail
    GND → GND rail
    WS  → GPIO 25
    SCK → GPIO 26
    SD  → GPIO 35
    L/R → GND rail

  Wire MicroSD module:
    VCC  → VIN rail (5V) — NOT 3.3V
    GND  → GND rail
    SCK  → GPIO 18
    MOSI → GPIO 23
    MISO → GPIO 19
    CS   → GPIO 5

  Wire SW2 (power switch, 3-pin SPDT):
    Common (middle) → XL6009E1 OUT+ (or your bench 5V supply positive)
    PIN A           → ESP32 VIN + SD VCC
    PIN B           → leave unconnected (NC)

  Wire SW1 (recording slider, 3-pin SPDT):
    Common (middle) → GPIO 4
    PIN A           → 3.3V  (slide this way = START recording)
    PIN B           → GND   (slide this way = STOP recording)

  Wire LEDs:
    GPIO 2  → 220Ω resistor → Green LED → GND
    GPIO 15 → 220Ω resistor → Red LED   → GND

  Wire battery voltage divider:
    BAT+ (TP4056 B+ pad or battery positive wire)
         → R3 (100kΩ)
         → GPIO 34 (ADC input)
         → R4 (100kΩ)
         → GND

  Wire decoupling capacitors:
    C1 (100µF) : + leg → VIN rail, − leg → GND (near ESP32 VIN pin)
    C2 (10µF)  : + leg → VIN rail, − leg → GND (near ESP32 VIN pin)
    C3 (100nF) : one leg → ESP32 3V3, other leg → GND
    C4 (100nF) : one leg → INMP441 VDD, other leg → GND
    C5 (100nF) : one leg → GPIO34 junction, other leg → GND

  Insert a MicroSD card (FAT32 formatted) into the module.

STEP 3 — Test
──────────────────────────────
  Open Arduino IDE Serial Monitor at 115200 baud.
  Power the ESP32.

  Expected Serial Monitor output on boot:
      === VoiceNote AI — ESP32-WROOM-32 ===
      [SD]   ✓ OK
      [WIFI] ✓ Connected — IP: 192.168.x.x
      [NTP]  ✓ 2026-04-26 ...
      [I2S]  ✓ Mic ready
      [READY] Flip UP to record, DOWN to stop & upload.

  Then:
    1. Green LED turns ON when WiFi connects
    2. Slide SW1 toward 3.3V → Red LED ON, Serial shows "[REC] ✓ Started"
    3. Speak into the microphone for 5–10 seconds
    4. Slide SW1 toward GND  → Red LED OFF, Serial shows "Uploading..."
    5. Serial shows "[HTTP] ✓ Upload successful!"
    6. Check web app — recording appears within 30–60 seconds

  If anything fails, check:
    - SD card is FAT32 formatted (not exFAT)
    - SD card VCC is on VIN rail, not 3.3V
    - GPIO 6–11 are NOT connected to anything
    - Check Serial Monitor for error messages

STEP 4 — Sign off before moving to PCB
──────────────────────────────────────────
  Get Ramayana's confirmation that the breadboard test passed before
  proceeding to Phase 2. Send a short video of the recording + upload working.

SECTION 7 — PHASE 2: PCB DESIGN IN EASYEDA
================================================================================

Tool: EasyEDA Standard (free, browser-based — easyeda.com)
      Do NOT use EasyEDA Pro (different file format, harder for review)

Board specifications:
  Size:   60mm × 60mm  (fits the 3D-printed enclosure)
  Layers: 2-layer
  Color:  Black soldermask (matches product aesthetic — optional but preferred)

── STEP 1: SCHEMATIC ───────────────────────────────────────────────────────────

Place these symbols in EasyEDA:
  - ESP32-WROOM-32 (search "ESP32-WROOM-32" or use LCSC C82899)
  - INMP441 (or place as 6-pin connector with correct net labels)
  - MicroSD slot (SPI + VCC + GND)
  - TP4056 module
  - XL6009E1 boost module
  - SPDT switch (3-pin) × 2
  - LEDs × 2
  - Resistors × 4 (2× 220Ω for LEDs, 2× 100kΩ for battery divider)
  - Capacitors × 5 (100µF, 10µF, 100nF × 3)

Label all nets clearly:
  +5V, +3V3, GND, BATT+,
  I2S_WS, I2S_SCK, I2S_SD,
  SPI_SCK, SPI_MOSI, SPI_MISO, SPI_CS,
  GPIO4, GPIO2, GPIO15, GPIO34

Run ERC (Electrical Rules Check) — fix all errors before moving to layout.

── STEP 2: PCB LAYOUT ──────────────────────────────────────────────────────────

Component placement order:

  1. ESP32-WROOM-32 — CENTER of board
       Orient so antenna end points AWAY from all other components
       (antenna area must be copper-free — see antenna rule below)

  2. INMP441 — TOP AREA, near the top edge
       The microphone opening must align with the mesh hole in the enclosure lid

  3. MicroSD module — RIGHT EDGE of board
       The card slot opening must align with the right-side cutout in the enclosure

  4. TP4056 module — BOTTOM EDGE, near USB-C side
       The USB-C port must align with the bottom enclosure cutout

  5. XL6009E1 — near TP4056, on power rail path

  6. SW1 (record toggle) — LEFT or FRONT EDGE
       Must align with the switch cutout in the enclosure side panel

  7. SW2 (power switch) — adjacent to SW1
       Must align with its cutout in the enclosure

  8. LED1 (green) + LED2 (red) — BOTTOM EDGE
       Must align with the LED holes in the enclosure base

  9. Decoupling capacitors — AS CLOSE AS PHYSICALLY POSSIBLE to their IC VCC pins
       C1 + C2 + C3 → within 3mm of ESP32 VIN/VCC pin
       C4           → within 2mm of INMP441 VDD pin
       C5           → within 2mm of GPIO34 pad

  10. Resistors R1, R2 — between GPIO pads and LED pads
      Resistors R3, R4 — near TP4056 B+ pad, away from I2S and SPI lines

Trace widths:
  Power traces  (+5V, +3V3, GND, BAT lines) : 1.0mm preferred, 0.5mm minimum
  Signal traces (I2S, SPI, GPIO)             : 0.3mm preferred, 0.25mm minimum

Ground plane:
  Bottom layer → full copper pour connected to GND net
  This eliminates most noise on the microphone and SD card lines

Antenna clearance rule (CRITICAL):
  The ESP32-WROOM-32 has its antenna on one short end of the module.
  In EasyEDA, mark a keepout zone around this end:
    - No copper pour
    - No traces
    - No components
    - No ground plane
  Violating this will kill WiFi range.

Mounting holes:
  Add 4 × M2 mounting holes (2.2mm drill) at board corners

Board outline:
  Draw a 60mm × 60mm closed rectangle on the Board Outline layer

── STEP 3: DRC ─────────────────────────────────────────────────────────────────

Run DRC (Design Rule Check) in EasyEDA.
Target: zero errors, zero airwires remaining.

SECTION 9 — PHASE 4: PCB ASSEMBLY AND TESTING
================================================================================

Tools needed:
  - Soldering iron (temperature-controlled, set to 320–350°C for lead-free solder)
  - Solder (0.8mm, lead-free or 60/40)
  - Flux (paste flux helps with small pads)
  - Multimeter
  - USB-C cable
  - MicroSD card (formatted FAT32)
  - Computer with Arduino IDE

STEP 1 — Inspect bare PCB
  Check for shorts, broken traces, missing pads.
  Compare against your EasyEDA layout visually.

STEP 2 — Solder in this order (easiest to hardest)
  1. Resistors R1, R2, R3, R4   (flat, easy)
  2. Capacitors C3, C4, C5      (small ceramics first)
  3. Capacitors C1, C2          (electrolytics — polarity matters, stripe = negative)
  4. LEDs                       (flat side of LED = cathode = GND side)
  5. ESP32-WROOM-32             (pin headers or direct solder)
  6. INMP441 module
  7. MicroSD module
  8. TP4056 module
  9. XL6009E1 module
  10. SW1, SW2                  (switches last — they are tall)
  11. LiPo battery connector    (JST 2-pin or solder wires directly)

STEP 3 — Pre-power checks with multimeter
  Before plugging in anything:
  a) Measure resistance between +5V and GND → should NOT be 0Ω (short)
  b) Measure resistance between +3V3 and GND → should NOT be 0Ω
  c) Visually inspect all solder joints under bright light or magnifier

STEP 4 — Set XL6009E1 output voltage FIRST
  Before connecting ESP32: power XL6009E1 alone, trim pot to exactly 5.0V.
  Too high will destroy the ESP32.

STEP 5 — First power-on
  Connect USB-C (no battery yet).
  TP4056 red LED should light up.
  ESP32 should boot — open Serial Monitor to confirm WiFi connects.
  Green LED should turn on when WiFi connects.

STEP 6 — Full function test
  Insert SD card, flip record switch, speak, flip back, confirm upload on web app.

    - Small circular hole (bottom-right) for green LED
    - Small circular hole (bottom) for red LED
    - 4 × M2 threaded inserts or screw holes at corners for PCB standoffs

  Internal stack (bottom to top):
    1. LiPo battery (sits in base, held with double-sided foam tape)
    2. PCB on M2 brass standoffs (3–5mm height to clear battery)
    3. Lid snaps or screws onto base

Print settings (recommended):
  Material:    PLA or PETG
  Layer height: 0.15mm (fine detail for cutouts)
  Infill:       25%
  Supports:     Yes for overhangs near cutouts

Final assembly steps:
  1. Press M2 brass inserts into base corners with soldering iron (heat-set)
  2. Secure LiPo battery in base with foam tape
  3. Connect battery JST connector to TP4056 B+/B−
     NOTE: TP4056 B− connects to battery negative AND to the common GND rail.
     Both connections required — without B− on GND rail, the circuit has no
     common ground reference and nothing will work.
  4. Screw PCB onto standoffs with M2 screws
  5. Route any wires for switches/LEDs if they are not directly on the PCB
  6. Close lid and secure with M2 screws

SECTION 11 — COMMON MISTAKES TO AVOID
================================================================================

── WRONG GPIO PINS ─────────────────────────────────────────────────────────────

  Old board (C3 Mini) vs current board (WROOM-32) — do NOT mix these up:

  Old C3 Mini pins (WRONG)  │  Current WROOM-32 pins (CORRECT)
  ──────────────────────────┼──────────────────────────────────
  I2S WS  → GPIO 4          │  I2S WS  → GPIO 25
  I2S SCK → GPIO 5          │  I2S SCK → GPIO 26
  I2S SD  → GPIO 3          │  I2S SD  → GPIO 35
  SD SCK  → GPIO 6          │  SD SCK  → GPIO 18
  SD MOSI → GPIO 7          │  SD MOSI → GPIO 23
  SD MISO → GPIO 2          │  SD MISO → GPIO 19
  SD CS   → GPIO 10         │  SD CS   → GPIO 5
  Toggle  → GPIO 8          │  Toggle  → GPIO 4
  Green LED → GPIO 0        │  Green LED → GPIO 2
  Red LED   → GPIO 20       │  Red LED   → GPIO 15
  Battery ADC → GPIO 1      │  Battery ADC → GPIO 34

  Rule: ALWAYS use Section 3 of this document. Never use another source.

── GPIO 6–11 ARE FORBIDDEN ─────────────────────────────────────────────────────

  On the ESP32-WROOM-32, GPIO6–GPIO11 are connected internally to the
  on-board SPI flash memory. Connecting anything to them will crash or
  permanently damage the board. Leave them completely unconnected.

── DO NOT CONNECT LED2 TO GPIO34 ───────────────────────────────────────────────

  GPIO34 is the battery ADC input. It must only connect to the midpoint of the
  R3/R4 voltage divider. LED2 (red, recording) goes to GPIO15.

── DO NOT SKIP DECOUPLING CAPACITORS ───────────────────────────────────────────

  The ESP32 pulls up to 250mA in bursts during WiFi transmit.
  The SD card pulls sudden current during write operations.
  Without decoupling capacitors, you will see:
    - Random ESP32 resets during WiFi upload
    - SD card file corruption
    - Audio noise / hissing
  All five capacitors (C1–C5) are required. Do not remove any.

── FORMAT THE SD CARD CORRECTLY ────────────────────────────────────────────────

  The firmware requires FAT32 format.
  Windows default for cards > 32GB is exFAT — the firmware cannot read this.
  Use a card that is 32GB or smaller, or manually format to FAT32.
  On Windows: right-click the card in File Explorer → Format → FAT32.
  On Mac: Disk Utility → Erase → MS-DOS (FAT).

── DO NOT CONNECT THE BATTERY BACKWARDS ────────────────────────────────────────

  LiPo batteries have red (positive) and black (negative) wires.
  The TP4056 module has B+ and B− pads clearly marked.
  Reversed polarity permanently destroys the TP4056 and may cause the battery
  to swell or vent. Double-check polarity before connecting.

── SET XL6009E1 VOLTAGE BEFORE CONNECTING ESP32 ────────────────────────────────

  The XL6009E1 boost converter has a trim pot. By default it may output 8–12V.
  This will instantly destroy the ESP32. Always measure and set to exactly 5.0V
  BEFORE connecting any other component.

── ANTENNA KEEPOUT IS NOT OPTIONAL ─────────────────────────────────────────────

  If you route copper pour or traces near the ESP32-WROOM-32 antenna area,
  WiFi range drops dramatically. Mark and enforce the keepout zone in EasyEDA.

── TP4056 B− MUST CONNECT TO GND RAIL ──────────────────────────────────────────

  TP4056 B− connects to battery negative AND to the common GND rail.
  If B− is only wired to the battery and not to the GND rail, the circuit
  has no common ground reference and nothing in the device will work.

── DO NOT MODIFY THE FIRMWARE ──────────────────────────────────────────────────

  The firmware is tested and working in production.
  Any change to GPIO numbers, I2S config, SPI config, or upload logic
  requires a full regression test on the breadboard before committing.
  If you think a change is needed, ask Ramayana — do not edit and assume.
